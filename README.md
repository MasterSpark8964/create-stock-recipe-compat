# Create Stock Recipe Compat 0.4.6-client.1

机械动力仓库管理员的 JEI 原料准备客户端附属。

[下载 0.4.6-client.1 Jar](https://github.com/MasterSpark8964/create-stock-recipe-compat/raw/refs/heads/main/downloads/create_stock_recipe_compat-0.4.6-client.1.jar)

## 前言

本人在游玩「无限模板」整合包时，希望能通过机械动力仓管更方便地为锻造台配方下单，于是围绕这个需求开始了一个 vibe coding 项目。

最初只是想补上锻造台的适配，后来逐步加入了缺料时展开中间配方、按材料批次下单，以及减少无效搜索的优化。这个项目从自己的游玩需求出发，但实现上尽量不绑定某一个整合包，也不修改机械动力原 Mod。

目前它仍是实验性作品。早期基础功能有实测记录，后续递归补料与优化版本主要经过代码检查和编译，尚未完成系统的运行验证。欢迎带着具体配方、版本信息和日志反馈问题，一起把它完善起来。

## 安装

仅在自己的客户端安装本附属，服务器及其他玩家无需安装。服务器仍需提供兼容的 Create 仓管与物流功能。更新时移除旧版附属 Jar，只保留一个版本。

| 组件 | 范围 |
| --- | --- |
| Minecraft | 1.20.1 |
| Forge | 47.4.18–47.x |
| Create | 6.0.8 |
| JEI Forge | 15.8.2.26–15.20.x |
| Java | 17 |

## 功能

- 原 JEI 加号保留工作台原生转移，并扩展锻造台、切石机和烹饪类配方的直接原料准备。
- 额外按钮点击后才搜索上级配方；成功后返回仓管并填写待发区，由玩家手动发送。
- 多层搜索支持工作台、锻造台、切石机、熔炉、高炉、烟熏炉与营火；接受模组或数据包注册在这些类型下的配方。
- 不展开模组机器、铁砧修复、盔甲纹饰、附魔、战利品、掉落、交易和 NST 上级路线。过滤羊毛反复染色，同时允许使用库存中的已染色羊毛。
- 按实际库存、数量和 NBT 分配材料，保留耐久弓等配方接受的已有材料，限制每单最多九种实际物品。
- 搜索中再次点击会取消；失败提示保持显示，再次点击只关闭提示，随后才可重新搜索。

它准备原料，不执行合成。手动发料使用 Create 原有请求，不添加服务端网络协议。

## 搜索与缓存

索引只复用当前客户端世界的一份；库存及订单在每次请求时重新检查。取消、切换界面、配方/标签更新与退出世界时清理相关状态，后台任务队列有界。默认活动计算预算 500 毫秒，搜索总耗时上限 30 秒；主线程回调按 tick 分摊。模组自身的单次回调不能被强制中断，因此不能保证所有整合包都完全无停顿。

## 配置与限制

配置文件：`config/create_stock_recipe_compat-client.toml`。

配方诊断 `general.enableRecipeDiagnostics` 和内存诊断 `general.enableMemoryDiagnostics` 默认关闭，记录仅写入本地。旧配置不会被新默认值覆盖；此前打开过记录的用户需自行关闭。

在仓管界面后续增加数量时，台阶等多产物配方可能按固定方案放大原料数量。

## 构建

需要完整 JDK 17，首次构建联网下载依赖。

```bash
sh ./gradlew test build
```

Windows 使用 `gradlew.bat test build`。输出在 `build/libs/`，发布包不包含测试源码。
